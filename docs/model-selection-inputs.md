# Model Selection Function Inputs

| Input | Fast / Low | Medium | Long / High | `None` |
|---|---|---|---|---|
| **Duration** | **Fast:** Finish quickly. | A moderate wait is acceptable. | **Long:** A longer run is acceptable. | No time preference. |
| **Budget** | **Low:** Keep spending low. | Allow moderate spending. | **High:** Allow higher spending when useful. | No budget preference. |
| **Intelligence** | **Low:** Basic capability is sufficient for routine tasks. | Needs reasoning and judgment. | **High:** Needs advanced reasoning for difficult tasks. | Infer the capability needed from the task. |
| **Autonomy** | **Low:** Frequent guidance is acceptable. | Occasional help is acceptable. | **High:** Work independently; ask only when necessary. | Infer the appropriate level from the task. |
| **Task Required Reliability** | **Low:** Occasional failures are acceptable. | Failures should be uncommon. | **High:** Failures must be very rare. | Infer the reliability needed from the task. |
| **Task Failure Consequence** | **Low:** Mistakes cause minor, easily reversible problems. | Mistakes cause meaningful rework or disruption. | **High:** Mistakes cause serious damage or losses that are difficult to reverse. | Assess the consequences from the task. |
| **Task Ease of Verification** | **Low:** Correctness is difficult to check. | Checking requires some review or testing. | **High:** Quick, reliable checks are available. | Assess how easily the result can be checked. |

`None` means **no explicit value supplied**. A higher budget or longer duration permits additional spending or time; it does not require it.
